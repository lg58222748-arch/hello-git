## 원본 컨셉: VitaDay

**핵심 철학:** "하루 한 화면, 이모지 한 줄, 끝."
**메인 비주얼 메타포:** 이모지가 텍스트를 대체하는 UI 언어. 영양제마다 고유 이모지, 한 달치는 이모지 격자로 시각화. 빼먹은 날은 흐릿한 윤곽 = "빈 칸의 미학".

## 원본 MVP 5개 기능

1. **하루 한 화면 (Today View)** — 영양제 = 이모지 카드, 탭 한 번 = 완료
2. **이모지 캘린더 (Month View)** — 한 달 = 이모지 격자
3. **영양제 등록 (Setup)** — 약통 사진 1장 → OCR 자동 추출
4. **하루 일과 기록 (Daily Note)** — 이모지 3개 + 한 줄 메모, 사진 첨부 가능
5. **통계 (Insights)** — 주간/월간 streak, 컨디션 이모지 ↔ 영양제 챙김률 상관

## 의도적 제외 (원본 브레인스토밍 시점)

- 소셜·공유 기능 — 1인용 깔끔함 우선
- 게이미피케이션·진화 이모지 — 복잡도 ↑
- 자동 재주문·커머스 — MVP 범위 초과
- 사운드/진동/AR — 깔끔함 저해
- HRV·스마트워치 자동 페어링 — 검증 어려움

## 브레인스토밍에서 살아남는 가치 (현재 브리프에 계승)

- **죄책감 없는 UX** ("빈 칸의 미학" 정신)
- **입력 부담 최소화** (V 체크 = 탭 한 번)
- **하루 한 화면 단순성**
- **1인용 도구로서의 명확한 포지셔닝**
