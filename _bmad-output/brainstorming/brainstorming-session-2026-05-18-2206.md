## Final Concept: "VitaDay"

### 핵심 철학
> **"하루 한 화면, 이모지 한 줄, 끝."**
> 입력 부담 0, 시각 만족도 최대.

### MVP 기능 5가지

**1. 하루 한 화면 (Today View)**
- 화면 중앙에 오늘 챙겨야 할 영양제가 이모지 카드 N개
- 탭 한 번 = 완료, 길게 누르기 = 사진 첨부(선택)
- 알림: 부드러운 진동 + 큰 이모지 (텍스트 없음)

**2. 이모지 캘린더 (월간 뷰)**
- 한 달이 이모지 격자로 표시
- 챙긴 날 = 또렷한 이모지 / 빼먹은 날 = 흐릿한 윤곽
- 홈 화면 위젯 노출

**3. 하루 일과 기록 (Daily Note, 선택)**
- 이모지 3개 + 한 줄 메모
- 사진 1장 첨부 가능
- 강제 X, 가볍게 남기는 흔적

**4. 통계 (Insights)**
- 주간/월간 streak
- 컨디션 이모지 ↔ 영양제 챙김률 상관 자동 시각화
- 차트 없이, 이모지 패턴만으로 인사이트

**5. 영양제 등록 (Setup)**
- 약통 사진 1장 → OCR로 성분/용량 자동 추출
- 영양제마다 이모지 1개 매핑 (기본 라이브러리 + 커스텀)

### Action Plan (다음 단계)

1. 핵심 사용자 페르소나 1-2명 정의 (예: "꾸준히 못 챙기는 30대 직장인")
2. 와이어프레임 5장 작성 (Today / Calendar / Note / Insights / Setup)

4. 종이/Figma 프로토타입으로 5명 인터뷰
